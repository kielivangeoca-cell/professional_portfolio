Problem-solving

GET /cases

Identify

Describe the problem clearly: what is happening, what should happen, and when it started.

Check

Test possible causes one at a time, starting with the simplest, until the real cause is found.

Document

Write down the cause, the fix and the lesson learned so the problem is easier to solve next time.

Example: computer cannot connect to Wi-Fi

  • Identify: the laptop shows it is connected, but there is no internet.
  • Check: confirm the adapter is on, run ipconfig, ping the router, then ping 8.8.8.8, then a website.
  • Document: note which step failed, how it was fixed, and the lesson: test each network layer in order.
